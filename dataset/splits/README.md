# 数据划分

本目录保存玩家 A 的完整训练池索引，以及玩家 B 从该训练池随机抽取的样本索引。

| 数据集 | A 的训练图片 | B 的默认 1% | 测试选模图片 | 原始尺寸 |
|---|---:|---:|---|---|
| [c10](c10/) | 50,000 | 500 | test，10,000 | 32×32 |
| [c100](c100/) | 50,000 | 500 | test，10,000 | 32×32 |
| [s10](s10/) | 5,000 | 50 | test，8,000 | 96×96 |
| [t200](t200/) | 100,000 | 1,000 | val，10,000 | 64×64 |

B 无放回抽取 `floor(训练池数量 × 抽样比例)` 个样本。每个 seed 对应一份固定随机排列，取前若干个编号；同 seed 下较小比例的子集包含在较大比例的子集中。

```text
c100/
├── train_index.tsv
├── train_source.json
└── seed_42/
    ├── order.txt
    └── ratio_0.01/
        ├── b_indices.txt
        └── manifest.json
```

| 文件 | 内容 |
|---|---|
| `train_index.tsv` | 完整训练池的样本编号、文件路径及行号 |
| `train_source.json` | 训练池规模、类别顺序与数据校验值 |
| `order.txt` | 当前 seed 对应的完整训练池随机排列 |
| `b_indices.txt` | B 抽中的训练样本编号 |
| `manifest.json` | 种子、比例、数量、类别统计与校验值 |

样本编号与行号从 `0` 开始。数据文件路径相对 `dataset/raw/<数据集>/`；单张 JPEG 的行号为 `0`。
