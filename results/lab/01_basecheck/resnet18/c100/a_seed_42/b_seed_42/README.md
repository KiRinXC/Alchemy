# Lab01 基线配置敏感性结果

在正式 Exp03 的作者 Top-12 Joint 上，仅将 B 的分类头换成 A 微调前的随机头，Best 测试准确率便从 **18.80% 升至 22.46%**。八个受测 Top-k 的变化方向一致。降低学习率也明显影响绝对准确率，但它同时降低各自的全保护黑盒水平，因此对相对黑盒差距的影响小得多。

阈值只在 Top-10～17 内逐点判定，命中后还可能再次超过阈值。例如 B0 在 Top-13 首次命中，此后只有 Top-17 再次命中。下文的平均变化均为八个受测 Top-k 的配对差值等权平均。

**RQ1 · 分类头能解释多少差异？** B1 与 B0 使用相同保护集合，仅分类头初值不同。换头使八个 Top-k 的 Best 均提高，增幅为 1.22～6.06 pp。Top-12 的 +3.66 pp 完整复现了用户提供的早期数值与正式基线之差。与此同时，All-Shield 下降 0.67 pp，使 Top-12 相对黑盒的优势增大 4.33 pp。受控结果表明，单独换头足以重现该幅度；早期运行的保护集合和其余条件未经核实，其历史差异的实际成因仍不能唯一确定。

**RQ2 · LR 和 WD 各改变多少？** B2 相对 B0 将 LR 从 0.1 降至 0.01，Joint Best 平均下降 3.21 pp，黑盒下降 2.84 pp，相对差距平均只下降 0.37 pp。B3 单独取消 WD，Joint Best 平均变化 +0.01 pp（各点 −0.34～+0.35 pp），黑盒下降 0.46 pp，相对差距在八个点都扩大，平均 +0.47 pp。B4 同时改变两项后，Joint Best 和相对差距平均变化分别为 −3.22 和 −0.39 pp。扣除两项单因素效应之和，组合的剩余效应分别为 −0.02 和 −0.49 pp。

**RQ3 · 换头效应是否随优化配置变化？** 八个 Top-k 在两套设置下都因换头获得更高的 Best。B1−B0 和 B5−B4 的平均绝对增益分别为 +2.91 和 +2.62 pp，平均相对黑盒增益分别为 +3.58 和 +2.48 pp。低 LR、零 WD 下，相对增益在每个点都减小，平均少 1.10 pp。以 Top-12 为例，绝对换头增益由 +3.66 变为 +3.07 pp，而换头对黑盒的影响由 −0.67 变为 +0.14 pp，两者共同使相对增益由 +4.33 变为 +2.93 pp。

本次结论限于 seed 42 和同一批 500 张查询图片。官方测试集参与 Best Epoch 和 Top-k 选择。八个保护规模对应不同场景，不能据此估计跨随机种子的误差。
