# 玩家 A 基础微调协议

使用真实类别标签，从固定版本的 ImageNet 预训练模型开始全量微调。全部官方有标签训练数据参与梯度更新，每轮使用官方测试集选模。

## 数据用途

| 数据集 | 训练图片 | 测试选模图片 | 模型输入 |
|---|---:|---|---|
| c10 | 50,000 | 官方 test 10,000 | 32×32 |
| c100 | 50,000 | 官方 test 10,000 | 32×32 |
| s10 | 5,000 | 官方 test 8,000 | 128×128 |
| t200 | 100,000 | 官方 val 10,000 | 224×224 |

不额外留出内部验证集。STL-10 的无标签数据和 Tiny-ImageNet 的无标签 test 不参与训练或选模。

训练数据保持官方文件的原始样本顺序，再由 DataLoader 每轮打乱。CIFAR 使用 RandomCrop(32, padding=4) 和随机水平翻转，均值为 `(0.4914, 0.4822, 0.4465)`，标准差为 `(0.2023, 0.1994, 0.2010)`；评估只做张量转换和相同归一化。STL-10 使用 Resize(128)、RandomCrop(128, padding=4) 和水平翻转；Tiny-ImageNet 使用 Resize(256)、RandomCrop(224) 和水平翻转。后二者评估使用对应中心裁剪与 ImageNet 归一化。

`run/dataset/split.py` 保存完整训练池索引及 B 的抽样索引。B 的默认 1% 对应 c10/c100 各 500 张、s10 50 张、t200 1,000 张。B 查询 A 的完整概率分布作为训练标签；测试选模数据不进入 B 的抽样池。

## 训练和选模

超参数统一读取 `configs/finetune.toml`：100 轮、batch size 64、交叉熵、SGD、初始学习率 0.1、momentum 0.5、weight_decay 5e-4、StepLR 每 60 轮乘以 0.1。第 1–60 轮学习率为 0.1，第 61–100 轮为 0.01。

所有模型参数参与训练，使用 FP32，不使用 AMP、早停或标签平滑。每轮保留不足一个批次的末尾样本。

每轮计算官方测试集准确率，满足 `test_accuracy >= best_accuracy` 时保存 `best.pth`；同分时保留较晚轮次，不按损失打破平局。该权重作为 A 的查询模型和 B 已知参数的来源。`last.pth` 保存最后完整轮次及恢复所需状态。

测试集参与选模，因此最高测试准确率是选模数据上的成绩，不是独立留出测试的估计。结果同时报告最佳轮次、最高测试准确率和最后一轮测试准确率。

## TensorShield 对照

论文 §8.1 Configuration（PDF 第 10 页）给出上述训练超参数；公开 MS 代码使用官方 train/test 划分，每轮通过 test 准确率选模。本实验采用这套数据用途与选模规则，并保留论文的 60 轮衰减间隔。

论文和代码的 `weight_decay` 都是 5e-4，区别是代码默认 `StepLR.step_size=30`。该值可以被命令行覆盖，因此默认值不能证明论文结果实际使用哪条曲线。本项目明确使用 60，不把它称为完全照搬公开代码默认配置。

## 复现与结果

种子和确定性开关来自根目录 `config.toml`。模型初始化、训练打乱和 DataLoader 使用同一个 seed，每轮不重置全局随机状态。默认 4 个数据加载进程、2 个 CPU 计算线程，不启用持久 worker。评估恢复训练进程的全局随机状态。

`summary.json` 保存最佳轮和最后一轮的训练/测试准确率与 loss，以及训练评估累计分钟数；`history.csv` 保存全部逐轮指标、学习率和耗时。准确率以百分数记录，累计耗时由逐轮秒数相加得到。

实际生效的训练参数随权重保存。断点包含优化器、学习率调度器，以及 Python、NumPy、Torch、CUDA 和两个 DataLoader 的随机状态；恢复时核对实际配置，不依赖结果目录中的配置副本。
